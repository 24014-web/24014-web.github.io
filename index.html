ABOUT NVOR TECH

Experiments
for the browser.

NVOR Tech explores interactive graphics made to run on the web. The current project combines a real-time Three.js scene, custom shaders, reflective planet surfaces, and direct controls for exploring each orbit.

The black-hole visuals are an art-directed interpretation, not a scientific simulation of a real black hole. The project page explains the rendering choices and interactions.

NVOR AI is also in development as an experimental local assistant exploring connectome-assisted language and source-backed retrieval. Its factual answer quality is still under evaluation, and it is not yet a public hosted service.
