02 / THE APPROACH

A local assistant
with a graph prior.

The project investigates whether a custom language decoder can work alongside a persistent graph-based workspace for conversation and reasoning. Its graph topology uses the Drosophila MaleCNS connectome as a computational prior; it is an engineering choice, not a model of a living brain.

The prototype also explores source-backed web lookup, local session memory, and retrieval from user-selected documents. Those are experimental components, and their presence does not establish reliable answers or improved reasoning.

03 / WHAT IS BEING EXPLORED

Build carefully.
Measure honestly.

NVOR AI is a research prototype, not a finished assistant. The development work focuses on making each part inspectable and testing whether it improves useful tasks.

01 / LANGUAGE

Custom decoder

The current design uses a connectome-conditioned language decoder rather than a separate pretrained general-purpose model. Its output still needs careful evaluation.

02 / CONTEXT

Graph and memory

The prototype pairs language generation with engineered graph state and bounded session memory. These mechanisms are software abstractions, not biological neural activity.

03 / EVIDENCE

Source-backed retrieval

Lookup and document retrieval are intended to expose supporting sources. Retrieved material is separate from generated text and does not guarantee that an answer is correct.

LIMITS AND AVAILABILITY

An experiment, not a released AI product.

The project is still in development, and its factual answer quality has not passed its acceptance checks. It is not a biologically faithful brain simulation, a conscious system, AGI, or a validated general-purpose assistant. NVOR Tech does not provide a hosted NVOR AI service or public model download on this website yet.
